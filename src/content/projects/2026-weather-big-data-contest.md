## 프로젝트 한눈에 보기

강원도 전신주 **1,387,831개**의 산불 위험도를 계산하고, 이 가운데 **118,805개**를 고위험 점검 대상으로 선별했다. 산불 발생과 세 종류의 비발생 대조군을 비교해 위험 요인을 찾고, LightGBM의 결과를 실제 점검 순서와 대시보드로 연결했다. 그 결과 <strong>2026 날씨 빅데이터 콘테스트 우수상(기상청장상)</strong>을 수상했다.

대시보드에서 점검 대상을 좁히는 순서는 다음과 같다.

1. 좌측 하단의 스크롤을 통해 날짜별 위험 전신주 비율과 수량이 높은 기상셀을 확인한다.
2. 셀 안에서 `대표 위험 pole` 점수가 높은 전신주부터 정렬한다.
3. `현재 플래그`(기상 조건)와 `습도`, `도로·WUI` 을 함께 확인한다.

## 해결하려던 문제

이 프로젝트의 목표는 **기상과 공간 조건을 함께 고려해 상대적으로 위험한 전신주를 선별하고, 실제 점검에 사용할 우선순위를 만드는 것**이었다. 이 문제 정의는 기존 강원도 산불발생확률모형이 남긴 한계에서 출발했다.

### 출발점이 된 선행연구와 한계

박흥석 외(2009)는 강원도 지역의 5년간 기상자료와 산불 발생자료를 분석하고, 10일 평균 미세연료수분지수(FFMC)를 이용한 로지스틱 산불발생확률모형을 제시했다. 이 연구는 캐나다 산불기상지수의 국내 적용 가능성을 확인했다는 점에서 중요한 출발점이었다.

다만 판별률은 **63.6%** 였으며, 논문에서도 지역별 기상자료를 더 세밀하게 분류할 필요가 있다고 설명했다. 또한 FFMC라는 단일 지수를 중심으로 모형을 구성했기 때문에 강원도 내부의 해안·내륙·산간 기상 차이와 지형·토지피복·도로·생활권 조건을 함께 설명하기에는 한계가 있었다.

| 선행연구에서 남은 한계 | 이번 프로젝트의 확장 |
| --- | --- |
| 10일 평균 FFMC 중심의 모형 | FFMC, DMC, DC, ISI, BUI, FWI 등 캐나다 산불기상지수 6종과 시간 단위 기상자료를 함께 사용했다. |
| 지역별 기상자료를 더 세밀하게 구분할 필요 | 행정구역 대신 관측소 영향권을 기준으로 강원도를 92개 기상셀로 나누고 ASOS·AWS 관측값을 보간했다. |
| 기상 조건만으로는 현장의 공간적 취약성을 충분히 설명하기 어려움 | 지형·토지피복·도로·생활권-WUI 접근성 정보를 결합했다. |
| 산불 위험 분석과 실제 설비 점검 사이의 간극 | 모델 점수를 약 138만 개 전신주에 적용해 상대적 취약도와 점검 우선순위로 연결했다. |

즉, 이번 프로젝트는 선행연구를 부정한 것이 아니라 **FFMC 기반 산불발생확률모형의 가능성을 출발점으로 삼아, 더 세밀한 지역 기상과 공간정보를 결합하고 실제 전신주 점검 단위까지 확장한 작업**이다.

<details>

캐나다 산불기상지수 시스템(Canadian Forest Fire Weather Index System)은 기온, 상대습도, 풍속, 최근 24시간 강수량으로 산림 연료의 건조 상태와 예상되는 산불 행동을 계산한다.

| 구분 | 지수 | 의미 |
| --- | --- | --- |
| 연료 수분 코드 | FFMC | 낙엽과 가는 표층 연료의 수분 상태를 나타내며, 빠르게 변하는 발화 가능성과 관련된다. |
| 연료 수분 코드 | DMC | 느슨하게 쌓인 중간층 유기물의 수분 상태를 나타낸다. |
| 연료 수분 코드 | DC | 깊고 치밀한 유기층의 장기적인 건조 상태를 나타낸다. |
| 산불 행동 지수 | ISI | FFMC와 풍속을 결합해 초기 확산 가능성을 나타낸다. |
| 산불 행동 지수 | BUI | DMC와 DC를 결합해 연소에 사용할 수 있는 연료량을 나타낸다. |
| 산불 행동 지수 | FWI | ISI와 BUI를 결합해 예상되는 산불 강도를 나타낸다. |

여섯 지수는 단독 위험등급이 아니라 기상·공간·지형·토지피복 변수와 함께 모델 입력으로 사용했다.

### 선행연구의 한계를 실제 문제로 확장한 방법

| 문제 | 판단 | 적용한 방법 |
| --- | --- | --- |
| 행정구역 평균 기상 | 같은 시군 안에서도 고도와 해안·내륙 조건에 따라 날씨가 달라 현장의 조건이 희석될 수 있다. | 관측소의 공간 영향권을 기준으로 강원도를 92개 기상셀로 나누고 시간별 기상을 연결했다. |
| 불균형 데이터의 정확도 | 학습 데이터에서 실제 산불은 9.11%뿐이므로 대부분을 비산불로 예측해도 정확도가 높게 나올 수 있다. | 후보 모델은 AUPRC로 비교하고, 운영 임계값은 산불 미탐을 더 중요하게 반영하는 F2 Score로 정했다. |
| 위험점수와 점검 순서의 차이 | 위험점수만 제시하면 약 138만 개 전신주 중 어디부터 확인할지 정하기 어렵다. | 점수를 상대적 취약도로 해석해 고위험 전신주를 선별하고, 기상셀별 점검 순서를 대시보드로 구현했다. |

목표는 개별 전신주의 산불 발생 여부를 단정하는 것이 아니다. 제한된 인력과 비용을 위험도가 높은 설비에 먼저 배분할 수 있도록 상대적인 위험순위를 제시하는 데 초점을 맞췄다.

## 데이터 구성과 분석 설계

분석 설계의 핵심은 **서로 다른 데이터의 공간·시간 단위를 맞추고, 산불이 발생하지 않은 조건을 비교할 대조군을 만드는 것**이었다. 산불 위치에 연결한 기준을 최종 전신주 예측에도 동일하게 적용했다.

### 행정구역 대신 92개 기상셀 사용

강원도 내 관측지점의 공간적 영향권을 반영하기 위해 Voronoi 기반으로 셀을 구축했다. 셀 중심점에서는 주변 ASOS·AWS 관측값에 거리의 역제곱 가중치를 적용한 IDW 방식으로 시간별 기상을 보간했다.

</figure>

산불과 대조군, 전신주는 좌표에 따라 기상셀에 배정하고 `기상셀ID + 기준시각`을 키로 기상자료를 연결했다. 같은 셀과 같은 시각에 속한 표본은 동일한 기상값을 사용한다. 따라서 모델의 기상값은 개별 좌표의 미세기상이 아니라 기상셀 단위의 지역 배경 조건으로 해석했다.

### 산불과 세 종류의 비발생 대조군 비교

발생 기록만으로 모델을 만들면 계절이나 장소의 차이를 산불 요인으로 오해할 수 있다. 실제 산불과 성격이 다른 세 종류의 비발생 대조군을 함께 사용해 시간에 따른 기상 변화와 공간적 취약성을 나눠 학습했다.

| 표본 | 구성 방식 | 학습 목적 |
| --- | --- | --- |
| `Target 1` | 실제 산불이 발생한 위치와 시각 | 산불 발생 조건 학습 |
| `Target 0A` 시간 대조군 | 산불 위치는 유지하고 같은 월·시간대의 다른 비발생 시점을 연결 | 같은 장소에서 기상 조건에 따른 차이 학습 |
| `Target 0B1` 공간 대조군 | 기후지형유형과 공간층을 맞춘 다른 위치에 산불의 월·시간 분포를 연결 | 계절이 비슷할 때 공간 특성에 따른 차이 학습 |
| `Target 0B2` 배경 대조군 | 층화 추출한 다른 위치에 2020-2021년의 시각을 무작위로 연결 | 일반적인 비발생 조건과 기준선 학습 |

실제 산불과 500m 이내이면서 발생 시각 전후 24시간에 해당하는 대조군 후보는 제외했다. 공간 대조군과 배경 대조군 사이에도 같은 후보점이 중복되지 않도록 분리했다. 최종 학습 데이터는 17,045건이며 실제 산불 1,553건과 비발생 표본 15,492건으로 구성됐다.

### 사용한 데이터와 학습 파이프라인

| --- | --- | --- |

### 데이터 누수를 막은 기준

- 직전 24·48시간 기상 집계는 현재 시각을 제외한 이전 관측값으로 계산했다.
- 캐나다 산불기상지수는 기준시각 이전에 이용할 수 있는 정오 값만 as-of 방식으로 연결했다.
- 실제 산불과 같은 위치의 시간 대조군은 동일한 `모델링_그룹ID`로 묶어 서로 다른 fold에 들어가지 않도록 했다.
- 결측치 처리와 범주형 인코딩은 각 학습 fold 안에서만 학습했다.
- 좌표, 사건 ID, 샘플 유형, 그룹 ID 등 표본을 식별하거나 분할하는 정보는 모델 입력에서 제외했다.
- 모든 후보 모델은 동일한 split manifest에서 비교했다.

## 모델 개발과 운영 기준

### 192개 후보를 같은 조건에서 비교

Random Forest, Extra Trees, HistGradientBoosting, XGBoost, LightGBM, CatBoost의 6개 알고리즘에 32개 변수 조합을 적용했다. 기상·공간 변수의 범위, 캐나다 산불기상지수 조합, 토지피복 사용 여부를 바꿔 성능 기여도를 확인했다.

5-fold 교차검증에서는 같은 산불과 연결된 시간 대조군을 `모델링_그룹ID` 단위로 묶었다. 모든 후보는 같은 split manifest에서 평가하고, 1차 비교에서 성능이 높은 모델을 Optuna로 튜닝했다.

| 모델 | 최고 OOF AUPRC |
| --- | ---: |
| LightGBM | **0.6932** |
| XGBoost | 0.6834 |
| CatBoost | 0.6821 |
| Random Forest | 0.6618 |
| Extra Trees | 0.6555 |
| HistGradientBoosting | 0.6470 |

실제 산불은 전체 학습 데이터의 9.11%였기 때문에 정확도보다 AUPRC를 사용했다. AUPRC는 위험점수가 높은 표본을 선택할 때 실제 산불이 얼마나 포함되는지를 재현율과 정밀도의 관계로 평가한다. 최종 LightGBM에는 기상·공간·산불기상지수·토지피복 정보로 구성한 58개 변수를 사용했다.

### F2 Score로 점검 범위 결정

위험한 산불을 놓치지 않으려면 재현율을 높여야 하지만, 점검 범위를 넓힐수록 인력과 비용이 증가한다. 재현율에 정밀도보다 두 배의 가중치를 주는 F2 Score로 두 조건의 균형점을 찾았다.

최고 F2 운영 임계값은 `0.0199793962581399`였다. 이 기준은 검증 표본의 14.67%인 2,500건을 고위험으로 선별하고, 실제 산불 1,553건 중 1,118건을 포착했다. 재현율은 71.99%, 정밀도는 44.72%, F2 Score는 0.6416이었다.

### 점검 수량이 정해진 경우의 성능

위험점수 상위 10%인 1,705건만 선택하면 전체 산불의 62.40%인 969건을 포착했다. 이 구간의 산불 비율은 56.83%로 전체 산불 비율 9.11%보다 **6.24배 높았다**. 같은 수량을 무작위로 점검할 때보다 산불 선별 효율이 6.24배 높다는 뜻이다.

### SHAP으로 확인한 판단 근거

SHAP 중요도 상위 변수는 비산림 WUI 접경, 도로 최단거리, 산림지역 최단거리, DC, BUI 순이었다. 상위 10개 변수는 전체 중요도의 48.07%를 차지했다. 모델은 생활권과 산림이 맞닿는 공간, 도로 접근성, 장기 건조도, 최근 강수 부족과 낮은 습도를 함께 사용해 위험순위를 정했다.

SHAP은 변수의 인과효과를 증명하지 않는다. 서로 연관된 기상지수와 습도·강수 변수가 함께 들어가므로 개별 변수의 방향은 다른 조건까지 고려한 모델 내부의 기여로 해석했다.

또한 LightGBM 점수에는 확률 보정을 적용하지 않았다. 따라서 임계값 `0.019979`를 산불 발생확률 1.9979%로 읽을 수 없다. F2 임계값과 상위 10% 기준은 발생 여부를 단정하는 선이 아니라 상대적 위험순위에 따라 점검 대상을 정하는 운영 기준이다.

## 전신주 적용 결과와 한계

전신주에 학습 데이터와 동일한 공간·지형·토지피복 변수를 연결하고, 여러 실제 기상 시점의 점수를 계산했다. 특정 시점의 `max_score`는 일시적인 이상값의 영향을 받을 수 있어 여러 시점 점수의 95분위수인 `p95_score`를 최종 위험점수로 사용했다.

| 기후지형유형 | 전체 전신주 | 고위험 전신주 | 유형 내 고위험 비율 |
| --- | ---: | ---: | ---: |
| 고지·산간형 | 362,392 | 38,507 | 10.63% |
| 영동 해안형 | 309,478 | 25,914 | 8.37% |
| 영서 내륙형 | 715,961 | 54,384 | 7.60% |
| 전체 | **1,387,831** | **118,805** | **8.56%** |

고지·산간형은 유형 내부의 고위험 비율이 가장 높았고, 영서 내륙형은 전체 전신주가 많아 고위험 전신주의 절대 수가 가장 많았다. 점검 계획에서는 취약 비율과 실제 작업 물량을 함께 봐야 한다.

현재 결과는 전신주 자체의 고장·발화 확률이 아니라 **전신주 주변 환경의 상대적 산불 취약도**다. 연구에는 전신주 화재·고장 이력과 현장 점검 결과가 없었고, 비용과 인력 절감 효과도 수치로 검증하지 못했다. 실시간 경보로 확장하려면 기상자료 자동 수집, 점수 재계산 주기, 현장 점검 결과를 이용한 재검증 절차가 필요하다.

## 문제를 해결하며 배운 점

이 프로젝트에서 가장 중요했던 판단은 **성능 수치보다 먼저 비교 기준과 실제 운영 방식을 정하는 것**이었다.

| 문제 | 적용한 방법 | 배운 점 |
| --- | --- | --- |
| 미래 기상정보가 학습 변수에 들어갈 수 있었다. | 선행 기상창을 `[기준시각-window, 기준시각)`으로 계산하고, 산불기상지수는 기준시각 이전의 정오 값만 연결했다. 같은 산불과 시간 대조군은 하나의 그룹으로 묶었다. | 모델 성능보다 먼저 예측 시점에 실제로 사용할 수 있는 정보인지 확인해야 했다. |
| 정확도가 높아도 실제 산불을 놓칠 수 있었다. | 후보 모델은 AUPRC로 비교하고 운영 임계값은 F2 Score로 선택했다. 점검 수량이 정해진 경우에는 상위 구간 포착률을 따로 계산했다. | 평가 지표는 모델 종류가 아니라 운영 목표에 맞춰야 했다. |
| 모델 점수를 발생확률로 오해할 수 있었다. | 확률 보정이 없는 점수임을 밝히고 상대적 위험순위와 점검 기준으로만 사용했다. | 수치와 함께 그 수치로 말할 수 없는 범위도 설명해야 했다. |
| 분석 결과가 점검 업무로 바로 이어지지 않았다. | 시점별 점수를 전신주별 `p95_score`로 요약하고, 기상셀과 대시보드에서 점검 순서를 확인하도록 바꿨다. | 모델 성능만으로는 현장에서 사용할 수 없다. 점검 단위와 작업량까지 설계해야 했다. |

EDA, 모델링, 대시보드는 각각 떨어진 결과물이 아니었다. 대조군에서 확인한 기상·공간 신호를 변수로 만들고, AUPRC와 F2로 선별 기준을 정한 뒤 전신주 단위 우선순위로 연결했다. 최종 결과를 설명할 때도 성능 수치와 함께 데이터 누수, 지역별 차이, 점수의 해석 한계를 밝혔다.

## 본선 발표 질의응답

<div class="weather-qa-list">
  <details>
    <summary>지역 구분을 실제 모델에도 반영했는가?</summary>
    <p>영동 해안형, 영서 내륙형, 고지·산간형 구분을 모델에 포함했다. 다만 유형 변수 자체의 영향력은 크지 않았고, 지역 차이는 기상·공간·산불기상지수 변수에 더 구체적으로 반영된 것으로 해석했다.</p>
  </details>
  <details>
    <summary>캐나다 산불기상지수를 강원도에 그대로 적용했는가?</summary>
    <p>외부 계산값을 가져온 것이 아니라 강원도 기상데이터로 6개 지수를 직접 계산했다. 지수 하나를 위험등급으로 쓰지 않고 모델 입력 변수로 사용해 EDA와 교차검증에서 유효성을 확인했다.</p>
  </details>
  <details>
    <summary>모델 점수는 대시보드의 점검 순위로 어떻게 연결되는가?</summary>
    <p>전신주 위치에 모델 입력변수를 연결해 시점별 점수를 산출하고, 여러 시점의 95분위수인 p95_score로 전신주별 상대적 취약도를 요약했다. 대시보드는 이 점수가 높은 전신주를 우선 제시한다.</p>
  </details>
  <details>
    <summary>점검 우선순위가 실제 비용 절감으로 이어지는가?</summary>
    <p>무작위 점검보다 위험순위를 근거로 대상을 정할 수 있다는 의의는 확인했다. 다만 예산 절감액과 인력 최적화 규모는 계산하지 못했으므로 운영 효과를 확정적으로 주장하지 않았다.</p>
  </details>
  <details>
    <summary>전신주 자체의 화재 가능성을 예측한 것인가?</summary>
    <p>아니다. 전신주 화재·고장 이력이 없으므로 전신주 주변 환경의 상대적 산불 취약도를 산출한 것이다. 결과는 예방 점검 순서를 정하는 참고자료로 사용해야 한다.</p>
  </details>
